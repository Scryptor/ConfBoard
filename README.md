# ConfBoard — онлайн-доска для Wi‑Fi сети

Совместная рисовальная доска для **Android-планшетов, телефонов и Android TV**, работающая в одной локальной Wi‑Fi сети. Один APK на все устройства, **без сервера** и без ручного ввода адресов: приложения находят друг друга сами.

Типичный сценарий: несколько планшетов рисуют на общей доске «как маркером» на совещании, а телевизор показывает её во весь экран.

> Название приложения на устройстве — «Онлайн доска», идентификатор пакета — `board.online`.

## Возможности

- **Автоматическое объединение.** Первый запустивший становится хозяином, остальные находят его по UDP-маяку и подключаются по TCP.
- **Живая синхронизация.** Штрихи, фигуры и текст видны всем **во время** рисования, а не после.
- **Нет единой точки отказа.** У каждого устройства полная копия доски. Если хозяин ушёл, его место занимает следующий участник, доска не теряется.
- **Несколько досок.** Хозяин хранит доски у себя: список (свежие сверху), создание с названием, открытие, переименование, удаление. Название текущей доски показано слева вверху.
- **Режим ТВ.** На телевизоре включается полноэкранный просмотр: всё содержимое само вписывается в экран, панели инструментов нет.
- **Показ экрана на ТВ.** Кнопка с трансляцией на планшете: нажавший становится ведущим, и все ТВ повторяют его масштаб и сдвиг. Ведущим становится тот, кто нажал последним. Повторное нажатие или уход ведущего возвращает ТВ к показу всей доски.
- **Режим ТВ на планшете.** Кнопка с монитором: планшет показывает доску как телевизор, а остальные устройства видят его как ТВ. Выход: тап по экрану → «Выйти из режима ТВ». Выбор запоминается. На настоящем ТВ переключателя нет.

### Инструменты

Маркер, линия, стрелка, прямоугольник, эллипс, текст, ластик (стирает частями с разрезанием линий и фигур или объект целиком, 4 размера), 10 цветов, 4 толщины, отмена и повтор своих действий, масштаб и сдвиг двумя пальцами, «показать всё», очистка доски.

## Как это работает

```
 Планшет A (хозяин) ◄──── TCP ────► Планшет B
        │  ▲                          Телевизор
        │  └──── TCP ────────────────►
        └─ UDP-маяк (broadcast, порт 45454, раз в секунду)
```

1. При запуске устройство слушает UDP-маяки. Если хозяина нет, оно само становится хозяином: открывает TCP-порт (выбирается системой) и раз в секунду рассылает broadcast с адресом, портом, идентификатором доски и временем начала хозяйствования.
2. Остальные устройства получают маяк, подключаются по TCP (топология «звезда» через хозяина) и отправляют свою копию доски. Хозяин объединяет элементы с учётом удалённых (tombstones) и рассылает результат всем.
3. Изменения передаются операциями `UPSERT` / `APPEND` / `REMOVE`. Штрих: `UPSERT` в начале, `APPEND` точек на каждый кадр, финальный `UPSERT` в конце.
4. **Смена хозяина.** Если хозяин пропал, новым становится следующий по порядку подключения участник, остальные переподключаются к нему по маяку.
5. **Два хозяина.** Если случайно появилось два хозяина, побеждает более «старый» (раньше стал хозяином, при равенстве — меньший `deviceId`), второй становится клиентом.
6. **Сохранение.** Сохраняет только текущий хозяин (автосохранение с задержкой ~1,5 с) в `filesDir/boards`. После смены хозяина сохранять начинает новый.

### Протокол

Кадр: `int длина | byte тип | payload`, соединение с `TCP_NODELAY`, чтение и запись в отдельных потоках.

| Тип | Назначение |
|---|---|
| `HELLO` / `WELCOME` | рукопожатие: устройство, доска, список участников |
| `OP` | операция над доской (`UPSERT`, `APPEND`, `REMOVE`) |
| `MEMBERS`, `MEMBER_UPDATE`, `PING` | участники, смена режима ТВ, проверка связи |
| `BOARD_LOAD`, `REQ_NEW_BOARD`, `REQ_OPEN_BOARD`, `REQ_LIST_BOARDS`, `BOARD_LIST`, `REQ_DELETE_BOARD`, `REQ_RENAME_BOARD`, `BOARD_RENAME` | управление списком досок |
| `REQ_PRESENT`, `PRESENTER`, `VIEWPORT` | показ экрана на ТВ |

Элементы доски: `Stroke` (точки), `Shape` (линия, стрелка, прямоугольник, эллипс), `Text`; у всех есть id, цвет и толщина. Подробности и принятые решения: [`docs/superpowers/specs/2026-11-10-onlineboard-design.md`](docs/superpowers/specs/2026-11-10-onlineboard-design.md).

## Использование

1. Установите APK на все устройства (см. «Установка»). Устройства должны быть в **одной Wi‑Fi сети**, а сеть не должна блокировать broadcast и обмен между клиентами (на некоторых гостевых сетях и роутерах включена «изоляция клиентов» — её нужно выключить).
2. Запустите приложение на планшете — откроется список досок. Создайте доску или откройте существующую.
3. Запустите приложение на остальных устройствах. Они подключатся сами.
4. На ТВ доска открывается сразу в полноэкранном режиме. Чтобы показать ТВ нужное место, нажмите на планшете кнопку трансляции.

## Установка

Готовый APK берите на странице [Releases](https://github.com/Scryptor/ConfBoard/releases). Установка по ADB:

```bash
adb -s <ip:порт> install -r app-release.apk
```

Требования: Android 7.0+ (minSdk 24), права только сетевые (`INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE`, `CHANGE_WIFI_MULTICAST_STATE`).

> Release-APK подписан **debug-ключом**. Для собственной публикации задайте свой ключ в `app/build.gradle.kts`. Обновление поверх APK с другой подписью невозможно — сначала удалите старую версию.

## Сборка из исходников

Нужны JDK 17 и Android SDK (укажите путь в `local.properties`: `sdk.dir=/путь/к/sdk`).

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17   # или ваш путь к JDK 17
./gradlew :app:assembleRelease                  # app/build/outputs/apk/release/app-release.apk (~1,5 МБ)
./gradlew :app:assembleDebug                    # отладочная сборка
./gradlew :core:test                            # тесты модели и сети (в т.ч. смена хозяина)
```

## Отладка

- Принудительный режим: `adb shell am start -n board.online/board.app.MainActivity --es mode tablet` (или `tv`).
- Логи: `adb logcat | grep OnlineBoard`.
- Симулятор клиента с компьютера (подключается к доске в сети и рисует демо):

  ```bash
  ./gradlew :core:simClient
  ```

## Структура проекта

```
core/   чистый Kotlin (JVM), без Android
        Model.kt, Board.kt        модель доски и элементов
        Codec.kt                  бинарный протокол
        Net.kt                    кадры, TCP-соединение, UDP-маяки
        Session.kt                поиск, хозяин, клиент, миграция хозяина
        UndoStack.kt              отмена/повтор своих действий
        Eraser.kt, Geometry.kt    ластик с разрезанием, геометрия
        BoardStore.kt             хранение досок
        src/test                  тесты и SimClient
app/    Android-приложение на Jetpack Compose
        BoardController.kt        инструменты, жесты, вид
        BoardRenderer.kt          отрисовка
        BoardCanvas.kt            холсты планшета и ТВ
        Ui.kt                     панели и диалоги
        Platform.kt, MainActivity.kt
docs/   дизайн-документ
```

## Технологии

Kotlin 2.0, Jetpack Compose (Material 3), Gradle 8 / AGP 8.7, чистые `java.net` сокеты, без сторонних сетевых библиотек.

## Ограничения первой версии

Нет выделения и перемещения объектов, вставки картинок, экспорта в PNG, произвольного выбора цвета, работы через интернет и шифрования. Отмена и повтор действуют только на собственные действия устройства; масштаб и сдвиг у каждого устройства свои.
